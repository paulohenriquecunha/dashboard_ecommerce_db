# E-Commerce Performance Insights

This project showcases a complete analytics workflow – from building the database (schema and seed in SQL) to BI modeling and visualization in Power BI.  
The **E-Commerce Performance Insights** dashboard provides a clear view of revenue, orders, average order value, logistics performance, and payment methods, with analysis by month, category, and product.

## Repository structure
- `dashboard/ecommerce_db.pbix` – Power BI Desktop file
