# E-Commerce Performance Insights

Este projeto apresenta um fluxo completo de analytics – criação da base de dados (schema e seed em SQL), modelagem para BI e visualização no Power BI. O dashboard **E-Commerce Performance Insights** oferece visão clara de faturamento, pedidos, ticket médio, desempenho logístico e meios de pagamento, com análise por mês, categoria e produto.
